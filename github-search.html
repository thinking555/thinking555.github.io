GitHub 搜索指引

整理 GitHub 仓库搜索常用限定符：按名称、描述、README、标签、语言、复刻数、仓库大小、Star 数和 topic 数快速缩小结果范围。

内容搜索 范围搜索 数量搜索

内容搜索

  • 关键字 in:name

    搜索仓库名称中的关键词。

  • 关键字 in:description

    搜索仓库描述中的关键词。

  • 关键字 in:readme

    搜索 README 阅读说明中的关键词。

  • 关键字 in:topics

    搜索作者添加的标签。

范围搜索

  • topic:你要搜索的topic

    限定搜索某个 topic 下的仓库。

  • language:搜索的语言

    限定搜索某种编程语言的仓库。

数量搜索

forks:n —— 按复刻数量搜索

限定符 示例 说明
forks:n forks:1000 匹配恰好有 1000 个复刻的仓库。
forks:n forks:5 匹配只有 5 个复刻的仓库。
forks:n forks:>=205 匹配具有至少 205 个复刻的仓库。
forks:n forks:<90 匹配具有少于 90 个复刻的仓库。
forks:n forks:10...20 匹配具有 10 到 20 个复刻的仓库。

打开复刻搜索开关

GitHub 搜索默认会隐藏部分复刻仓库，可以用下面的限定符调整结果范围。

限定符 示例 说明
fork:true fork:true 搜索结果包含复刻的仓库。
fork:only fork:only 搜索结果只包括复刻的仓库。

size:n —— 按仓库大小搜索

限定符 示例 说明
size:n size:1000 匹配恰好为 1 MB 的仓库。
size:n size:>=30000 匹配至少为 30 MB 的仓库。
size:n size:<50 匹配小于 50 KB 的仓库。
size:n size:50...120 匹配介于 50 KB 与 120 KB 之间的仓库。

stars:n —— 按 Star 数搜索

限定符 示例 说明
stars:n stars:500 匹配恰好具有 500 个星号的仓库。
stars:n stars:10...20 匹配具有 10 到 20 个星号的仓库。
stars:n stars:>=500 fork:true language:php 匹配具有至少 500 个星号、包含复刻仓库、以 PHP 编写的仓库。

topics:n —— 按标签数搜索

限定符 示例 说明
topics:n topics:5 匹配具有 5 个主题的仓库。
topics:n topics:>3 匹配具有超过 3 个主题的仓库。
topics:n topics:100...150 language:php 匹配 topic 数在 100 到 150 之间、以 PHP 编写的仓库。
