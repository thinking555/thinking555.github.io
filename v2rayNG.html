使用 v2rayNG 给 Switch 加速下载

具体操作和主机游戏加速器的热点加速差不多。

方案说明

这个方法的核心是：先在手机上开启 v2rayNG 代理，再通过手机热点或 Wi-Fi 中继共享给 Switch。

需要的东西：安卓手机、switch、v2rayNG软件

操作步骤

  1. 打开 v2rayNG，导入节点并开启代理。
  2. 进入设置，把 “允许来自局域网连接” 打开。
  3. 记录 “本地代理端口”，后面在 Switch 上要用到。
  4. 开启手机热点，或者使用 Wi-Fi 中继。
  5. 让 Switch 连接到这个热点网络。
  6. 在 Switch 的网络设置中，进入当前热点的详细设置，把 “代理服务器设置” 改为启用。
  7. 在 服务器 一栏填写手机的本地 IP 地址，一般是 192.168.x.x 这种格式。
  8. 在 端口 一栏填写前面在 v2rayNG 里记录的本地代理端口。
  9. 保存设置后，Switch 就会通过手机代理翻墙。
小提示： 在可以使用软件的系统，没必要用这个方法，无需必要不要去做“奥卡姆剃刀原理”。这个方法无法使用YouTube。

v2rayNG 设置：

在设置中开启“允许来自局域网连接”，并记下“本地代理端口”。

怎么查看手机本地 IP：

不同设备查看方式略有不同。通常你需要记录热点网络里的 路由器地址 或 DNS 地址， 再把它填到代理设置里作为服务器地址使用。

Switch

IP 地址查看方法：连接热点后 → 设置 → 互联网 → 把首选 DNS记录下来。

连接热点后，在 Switch 的互联网设置中记录“首选 DNS”。

Mac

IP 地址查看方法：连接热点后 → 设置 → Wi-Fi → 详细信息 → 拷贝下路由器地址。

代理设置：设置 → Wi-Fi → 详细信息 → 代理 → 开启 SOCKS 代理 → 把路由器地址填入服务器栏 → 把 NG 设置的端口填入端口栏 → 保存。


iOS

IP 地址查看方法：连接热点后 → 设置 → 无线局域网 → 点击当前网络右侧的 i → 拷贝下路由器地址。

代理设置：设置 → 无线局域网 → 点击当前网络右侧的 i → 配置代理 → 手动 → 把路由器地址填入服务器栏 → 把 NG 设置的端口填入端口栏 → 保存。


Windows

IP 地址查看方法：查看当前 Wi-Fi 属性 → 复制 IPv4 DNS 服务器。

代理设置：连接热点后 → 网络设置 → 代理 → 开启手动设置代理 → 把 DNS 服务器填入地址栏 → 把 NG 设置的端口填入端口栏 → 保存。


Android（小米）

IP 地址查看方法：连接热点后 → 设置 → 网络详情 → 拷贝下路由器地址。

代理设置：设置 → 网络详情 → 代理 → 手动 → 把路由器地址填入主机名栏 → 把 NG 设置的端口填入端口栏 → 保存。

补充说明：不同系统显示名称可能略有区别，例如“路由器”“网关”“DNS”或“IPv4 DNS 服务器”，只要按对应步骤填写即可。

其他代理软件

如果你不用 v2rayNG，也可以使用其他支持局域网共享的代理软件。 核心思路一样：开启局域网访问，并记下对应端口，然后在设备里手动填写代理地址和端口。

Clash Meta

设置 → 覆写 → 将 HTTP 端口 设置为 10808 → 开启 允许来自局域网的连接。

Hiddify

设置 → 入站 → 开启 允许来自局域网的连接 → 将 混合端口 设置为 10808。

Shadowrocket

设置 → 代理共享 → 启用共享。

说明：Shadowrocket 和上面的方式略有不同，只要设备连接到同一个 Wi-Fi 即可使用共享代理。

NekoBox / Surfboard / FlClash

这几个安卓代理软件也可以。只要找到 “局域网共享”、“允许局域网连接” 或类似选项并开启即可。

补充说明：不同软件显示的端口类型可能是 HTTP、SOCKS 或混合端口。 实际填写时，以软件当前开启的共享端口为准。
